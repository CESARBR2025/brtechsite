# 🟨 3. CALCULADORA DE MERMA (ROI SIMULATOR 🔥)

### Input único:

- Merma diaria estimada (MXN)

## Cálculos

### 💸 Pérdida mensual

```ts

```

### 💸 Pérdida anual

```ts

```

### 💸 Pérdida a 3 años

